# Rick and Morty

Projeto desenvolvido para praticar consumo de API

A aplicação utiliza a Rick and Morty API para buscar personagens da série pelo nome e exibir algumas de suas informações.

## Funcionalidades

- Busca de personagens pelo nome
- Exibição da imagem do personagem
- Exibição do nome
- Exibição do status
- Tratamento de erros quando o personagem não é encontrado

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Fetch API
